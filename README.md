# File-Organizer

Потужний та швидкий інструмент командного рядка (CLI) на базі Node.js, розроблений для автоматичного аудиту папки завантажень (`Downloads`) та будь-яких інших директорій. Допомагає очистити хаос: знайти дублікати за допомогою хешування вмісту, розсортувати файли за категоріями та безпечно видалити застарілі дані.

Проєкт демонструє практичне застосування асинхронного програмування, роботи з файловою системою, потоків даних (Streams) та подієвої архітектури в Node.js.

## Можливості

| Команда      | Що робить                                                                   |
| ------------ | --------------------------------------------------------------------------- |
| `scan`       | Рекурсивне сканування директорії, детальна статистика                       |
| `duplicates` | Пошук дублікатів по SHA-256 хешу                                            |
| `organize`   | Копіювання файлів у категорії `Documents/Images/Archives/Code/Videos/Other` |
| `cleanup`    | Пошук та видалення файлів старіших за N днів (dry-run за замовчуванням)     |

## 📂 Структура проєкту

```text
file-organizer/
├── package.json         # Скрипти запуску та конфігурація ES Modules
├── README.md            # Документація застосунку
├── file-organizer.js    # Головний файл (Точка входу CLI, обробка подій)
└── lib/                 # Модулі бізнес-логіки команд
    ├── utils.js         # Допоміжні утиліти (прогрес-бар, формати, помилки)
    ├── scanner.js       # Клас Scanner (Рекурсивний обхід та аналітика)

```

## Встановлення

```bash
git clone <repository-url>
```

## Швидкий старт

```bash
npm run scan -- ~/Downloads
npm run duplicates -- ~/Downloads
npm run organize -- ~/Downloads --output ~/Organized
npm run cleanup -- ~/Downloads --older-than 90 --confirm
```

Подвійний дефіс `--` передає всі наступні аргументи напряму в скрипт.

## Детальні приклади команд

### 1. `scan <directory>`

Рекурсивно обходить `<directory>` (та всі піддиректорії), збирає розмір і дату
модифікації кожного файлу, після чого друкує звіт: загальна кількість і розмір,
розподіл по розширеннях, по віку (7/30/90+ днів), топ-3 найбільших файли,
найстаріший файл.

```bash
node file-organizer.js scan ~/Downloads
```

### 2. `duplicates <directory>`

Рахує SHA-256 для кожного файлу. Виводить групи дублікатів та
підсумкове "витрачене" місце.

```bash
node file-organizer.js duplicates ~/Downloads
```

### 3. `organize <source> --output <target>`

Копіює (не переміщує!) файли з `<source>` у `<target>`, розкладаючи по категоріях.
Категорії визначаються за розширенням; невідомі розширення потрапляють у `Other`.
Якщо файл з такою назвою вже існує в цільовій папці — додається суфікс `(1)`, `(2)`
і так далі.

```bash
node file-organizer.js organize ~/Downloads --output ~/Organized
```

Опції:

- `--output <path>` — обов'язкова цільова директорія.

### 4. `cleanup <directory> --older-than <days> [--confirm]`

Знаходить файли, у яких `mtime` старший за вказану кількість днів. Без прапорця
`--confirm` нічого не видаляє — лише друкує список (dry-run).

Опції:

- `--older-than <days>` — кількість днів (обов'язково, число ≥ 0).
- `--confirm` — власне видалити файли. За замовчуванням — лише попередній перегляд.

```bash
# попередній перегляд
node file-organizer.js cleanup ~/Downloads --older-than 90

# реальне видалення
node file-organizer.js cleanup ~/Downloads --older-than 90 --confirm
```
